# A-real-world-analytics-internship-with-CRM-sales-data-exported-from-the-Prog-Academy-system.-
Dashboard based on cleaned data. The dashboard shows sales by UTM tags, courses, and managers.

Всього 927 Лідів за період квітень-червень 2026. 
Сума продаж 870000 
По UTM-джерелам які привели до продажів
utm-source:
- основне джерело трафіку google(найбільша доля в стовбчатій діаграмі)
- chatgpt, telegram - незначні джерела.
utm-medium:
- з вказаних джерел перше місце cpc (31,03%) по секторній діаграмі
-  broadcast 5,17%
Аналіз роботи менеджерів
- Найактивніший менеджер Oksana B (510000)
Аналіз по курсам:
Продаж курсів QA-тестування принес найбільший прибуток (320000), QA Automation (150000), Data Analytics (150000) 
Проблеми з даними. Велика кількость лідів з продажами без utm-міток - треба покращити відстеження трафіку.
