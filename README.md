# A-real-world-analytics-internship-with-CRM-sales-data-exported-from-the-Prog-Academy-system.-
Dashboard based on cleaned data. The dashboard shows sales by UTM tags, courses, and managers.

Всього 178 Лідів за період квітень-червень 2026. 
Сума продаж 5000 (тільки один курс Data Analytics online в травні), respons user Oksana B., modified by Ivan M., created on 24/05/2026, utm мітки відсутні.
Травень - єдиний місяць з продажами, найактивніший місяць по кількості Лідів 99. Квітень - 75 Лідів. Червень - дані неповні, місяць не закінчився. 
По UTM-джерелам
utm-source:
- основне джерело трафіку google(найбільша доля в стовбчатій діаграмі)
- email на другому місці в травні по кількості лідів
- facebook, instagram, chatgpt, dou - незначні джерела.
utm-medium:
- перше місце по кількості лідів платна реклама cpc (18,54%) по секторній діаграмі
- друге місце по кількості лідів broadcast (9,55%) по секторній діаграмі
- bio, channel, forum - незначні джерела
Аналіз роботи менеджерів
- Найактивніший менеджер Oksana B (79 оброблених лідів)
utm-campaign:
- перше місце da_free_course_v2 близько 8% лідів
- друге місце pmax_ai_ua близько 4% лідів
Проблеми з даними. Близько 70% лідів без utm-міток - треба покращити відстеження трафіку. Більшість курсів показують 0 продаж.
